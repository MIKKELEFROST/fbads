# fbads — driftsviden for Meta-annoncering

Repoet indeholder **ingen kode**. Det er hukommelse for planlagte kørsler:
driftsviden om Meta-annoncering for kunder hos Frost Digital /
onlinemarketing.nu. En planlagt kørsel starter uden hukommelse fra tidligere
sessioner, så alt der skal overleve, står skrevet her.

## Start her
- **[`CLAUDE.md`](CLAUDE.md)** — den fulde driftsviden, herunder hvorfor
  lead-oplysninger skal hentes via Zapier og ikke via Meta Ads MCP
- **[`routines/`](routines/)** — én fil per tilbagevendende rutine

## Rutiner
- [Holmsmaler — leads fra Meta Ads](routines/holmsmaler-leads.md)

Overvej at sætte det til privat.
